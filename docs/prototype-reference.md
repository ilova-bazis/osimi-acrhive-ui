# Prototype Reference

The former routed visual prototypes and component gallery were removed from the application route graph. They remain available through repository history for design reference, but they are not compiled, linked, imported, or served by the production application.

Production implementations live under `src/routes/objects/**`, `src/lib/components/object-detail/**`, and `src/lib/components/object-edit/**`. Copying an idea from historical prototype code requires implementing it against production service contracts and placing it in a production-owned namespace.
